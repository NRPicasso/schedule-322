# Расписание 322

Сайт с расписанием, аудиториями и домашними заданиями группы 322 (РГУП, СЗФ).

- **Группа** открывает ссылку и видит «Сегодня», «Завтра», «Неделю» и «ДЗ». Видны переносы, отмены и замены аудиторий.
- **Активисты** заполняют неделю на странице «Для активистов» по личному коду. Отсюда же копируют текст для Telegram в привычном оформлении.
- Данные хранятся в Google Таблице «Расписание 322». Записывает в неё небольшой скрипт Google Apps Script. Сервер и хостинг оплачивать не нужно.

Ссылку на сайт рассылаем только внутри группы. Сайт закрыт от поисковиков: на каждой странице стоит `noindex`.

---

## Для группы

- Откройте ссылку из закрепа. После 18:30 (и в воскресенье) сайт сам показывает следующий учебный день.
- **Как приложение.** Сайт можно поставить иконкой на главный экран. Тогда он открывается одним нажатием и без интернета.
  - iPhone: в Safari «Поделиться» → «На экран „Домой“».
  - Android: кнопка «Установить» внизу страницы. Она появляется с третьего посещения. То же самое есть в меню Chrome: «Добавить на гл. экран».
- **Без интернета** показывается последняя загруженная неделя и плашка «Нет связи… Показано сохранённое от …».
- Изменения последних 48 часов помечены «изменено недавно».

## Для активистов

1. Откройте страницу «Для активистов» — это `admin.html` рядом с адресом сайта. Введите свой код из 6 цифр, его выдаёт Еремей. Галочка «Запомнить на этом телефоне» избавит от ввода в следующий раз.
2. **Подсказки.** При первом входе появляются три подсказки. Повторить их можно кнопкой «?» вверху.
3. **Какая неделя открывается.** С пятницы 12:00 до воскресенья — следующая, в остальное время — текущая. Неделю переключают стрелки вверху.
4. **ДЗ — кнопка «Заполнить».** Она проводит по всем семинарам недели:
   - **ссылка:** в Telegram нажмите на сообщение → «Копировать ссылку», здесь — «Вставить ссылку». Тема чата проверится сама: если ссылка из темы другого предмета, появится предупреждение;
   - **вставка с текстом:** можно вставить кусок сообщения целиком. Ссылки уйдут в список, текст — в подпись;
   - **«Как в прошлый раз»** подставляет ДЗ прошлого занятия. Частые подписи («Доклады» и т. п.) вставляются одной кнопкой;
   - **«ДЗ нет»**, если задания нет. Группа увидит «ДЗ нет».
5. **Карточка пары** открывается нажатием на пару:
   - подпись, ссылки, «ДЗ нет»;
   - «Изменения в этот день»: аудитория, время, преподаватель — «только в этот день» или «с этого дня и дальше» (можно с датой «по»);
   - перенос: с предпросмотром «было → стало» и предупреждениями. ДЗ переезжает вместе с парой;
   - отмена с причиной — пара остаётся зачёркнутой, «Вернуть пару» возвращает её.
6. **Доп. пара** — кнопка «+ пара» в шапке дня. **Пометка дня** («Сменка», «Сдаём КСУ») — «+ пометка».
7. **Текст для Telegram** — кнопка «Telegram» внизу. Вкладки:
   - «По дням»: кнопка «Скопировать понедельник» после копирования превращается в «Скопировать вторник» и так далее;
   - «Вся неделя»;
   - «Изменения»: готовые строки «❗ …» о заменах, переносах и отменах.

   Если день изменили после копирования, у него появится «!» — сообщение в группе нужно поправить. В карточке изменённой пары тоже есть готовое сообщение.
8. **Сохранение.** Всё сохраняется само, внизу видно «Сохранено». Плашка «Отменить» вверху держится 10 секунд.
   - **Без интернета** правки копятся в телефоне и уходят сами, когда сеть вернётся. Дублей не бывает.
   - **Если два активиста правят одну пару**, второй увидит выбор: «вариант другого» / «мой вариант» / «объединить ссылки». Молча ничего не затирается.
   - **Журнал.** Каждая правка записывается в лист «Журнал» таблицы: кто, когда, что было, что стало.
9. **Код не подходит** — напишите Еремею. После 10 неверных попыток вход для всех закрывается на 10 минут (защита от подбора кода).

Пожалуйста, не пишите в ДЗ фамилии одногруппников: сайт открыт всем, у кого есть ссылка (см. «Персональные данные» ниже).

## Для владельца (Еремей)

### Как устроено

```
site/                 сайт (GitHub Pages): обычные HTML, CSS и JS-модули, без сборки
  index.html          экран группы
  admin.html          редактор активистов
  src/schedule.js     сборка дня: шаблон верх/низ → постоянные замены → записи дня → переносы и доп. пары → номера
  src/telegram.js     тексты для Telegram
  src/store.js        очередь правок (работа без сети, «Отменить», версии)
  src/config.js       адрес веб-приложения Apps Script
  sw.js               работа без сети — создаётся командой, руками не править
  manifest.webmanifest, admin.webmanifest, icons/   «как приложение»
  data/               шаблон и история 14.09–31.10 — для локальной работы и тестов
apps-script/
  code.src.js         исходник серверной части
  Code.gs             то, что вставляется в редактор Apps Script (собирается командой)
tests/                проверки: node --test (логика) и tests/e2e (браузер)
tools/                build-gs.mjs (Code.gs), build-sw.mjs (sw.js)
```

### Таблица

Листы: «Шаблон», «Предметы», «Правила» (постоянные замены), «Записи» (ДЗ и разовые замены по дням), «Доп_пары» (переносы и дополнительные пары), «Дни» (пометки), «Журнал», «Настройки».

- **Конец семестра и опорная неделя** задаются в листе «Настройки»: `конец_семестра`, `опорная_неделя`, `опорная_половина`, `начало_семестра`, `завтра_после`. Сайт подхватывает изменения в течение минуты (у сервера кэш на 60 секунд).
- **Новый семестр.** Поправьте лист «Шаблон»: строка — пара; `неделя` — верх, низ или обе; `день` — 1 = пн … 6 = сб. Заголовки столбцов не переименовывайте: по ним сервер находит данные.

### Коды активистов

Коды создаются в редакторе Apps Script: выберите функцию `createActivistCodes` → «Выполнить» → коды появятся в «Журнале выполнения». В таблице хранятся не сами коды, а их отпечатки (SHA-256).

Повторный запуск выдаёт **новые коды всем**: старые перестают работать. Так отзывают код, если он ушёл не туда. Список имён — переменная `ACTIVISTS` в `apps-script/code.src.js`.

### Изменили серверную часть (`apps-script/code.src.js`)

1. `node tools/build-gs.mjs` — соберёт `apps-script/Code.gs`.
2. Вставьте содержимое `Code.gs` в редактор Apps Script вместо старого и нажмите «Сохранить».
3. «Начать развертывание» → «Управление развертываниями» → карандаш → «Версия: Новая версия» → «Начать развертывание». Адрес сайта при этом **не меняется**.

### Изменили сайт (`site/`)

1. `node tools/build-sw.mjs` — обновит список файлов для работы без сети (`site/sw.js`). Тест `tests/sw.test.js` напомнит, если забыть.
2. `node --test` — все проверки логики должны пройти.
3. Отправьте изменения на GitHub. У тех, кто уже открывал сайт, появится плашка «Сайт обновился · Обновить».

### Запустить у себя на компьютере

```bash
cd site && python3 -m http.server 8766    # открыть http://localhost:8766 и http://localhost:8766/admin.html
node --test                               # из корня проекта: проверки логики, Node 18+
```

Сайт на компьютере берёт данные с настоящего сервера (адрес в `site/src/config.js`). Если адрес стереть, он покажет данные из `site/data` — только просмотр.

Проверки в браузере (`tests/e2e/*.cjs`) запускаются через Playwright. Он ставится отдельно, около 500 МБ браузеров, поэтому на Mac его нет; эти проверки прогоняются в облачной среде Claude:

```bash
SITE=http://localhost:8766 ROOT=$PWD node tests/e2e/group.e2e.cjs
SITE=http://localhost:8766 ROOT=$PWD node tests/e2e/admin.e2e.cjs
ROOT=$PWD node tests/e2e/pwa.e2e.cjs
```

### Персональные данные

Открытый по ссылке сайт — это публикация (Федеральный закон от 27.07.2006 № 152-ФЗ «О персональных данных»). Что сделано:

- `noindex` на всех страницах;
- ссылка рассылается только в группе;
- в данных нет телефонов и почт.

Чего сделать нельзя: закрыть сайт от того, у кого уже есть ссылка. Поэтому в ДЗ не пишем фамилии одногруппников, а преподаватели указаны так же, как в официальном расписании вуза.

`robots.txt` намеренно не добавлен:

- поисковик читает его только в корне домена, а сайт будет лежать в подпапке (`…github.io/<репозиторий>/`);
- запрет в `robots.txt` не даёт поисковику увидеть `noindex`, а страница может попасть в выдачу по внешней ссылке.
