## Ошибки

### 1. Два экрана противоречили друг другу о постоянной замене — серьёзность: мелочь (исправлено)
- Шаги: есть бессрочная постоянная замена (ОСД — аудитория 400) → «Новая версия с даты».
- Ожидалось: экран новой версии пишет, что замена вписана в пару, и «Что изменится» не называет её потерянной.
- Получилось: «Что изменится» писал «Постоянные замены прежней версии в эту не переходят: ОСД — аудитория 400», хотя значение уже стояло в паре.
- Исправление (коммит a9586a6): замена, значение которой уже есть в паре новой версии, в предупреждение не попадает. Если активист потом вернёт прежнюю аудиторию — предупреждение появится. Добавлен тест.

### 2. На экране 320 px кнопка «Выйти» уходит на вторую строку — серьёзность: мелочь (оставлено)
- На самых узких телефонах (320 px) в строке с именем четыре кнопки: «Шаблон», «Как видит группа», «?», «Выйти». Последняя переносится на отдельную строку.
- Ничего не обрезано и не перекрыто, прокрутки вбок нет. Оставлено как есть: на 360 px и шире всё помещается.

- `.env` игнорируется (`.gitignore:1`); `materials/` (переписка) в git не попала.
- Зависимостей нет (`package.json` без `dependencies`, нет `node_modules`) — аудит `npm audit` не нужен.
- Пользовательский ввод не попадает в HTML: только `textContent`; ссылки — только `http(s)` (`safeLink`), `rel="noopener"`.
- Сервер: каждая операция проверяется (типы, длины, даты, id пар, версии), весь запрос под блокировкой, ошибки — короткие тексты без стека.
- CORS: Apps Script отдаёт всем (так устроен веб-сервис Google); данные расписания и так открыты по ссылке, запись — только по коду.
- Адрес веб-приложения в `site/src/config.js` — не секрет (без кода записать нельзя).

## Ошибки

### 1. Код можно подобрать за семестр — серьёзность: важно
- Шаги: автоматический перебор 6-значных кодов с паузами по правилу блокировки (10 попыток → 10 минут).
- Ожидалось: перебор практически невозможен.
- Получилось: до 1440 попыток в сутки; при 3 действующих кодах из 900 000 вероятность угадать за 110 дней ≈ 1 − e^(−110·1440·3/900000) ≈ 41 %. Попутно перебор держит сохранение закрытым для всех (это заметно, но код всё равно может быть найден).
- Предлагаемое исправление: нарастающая пауза (10 → 20 → 40 мин … до 6 часов, сброс через сутки без ошибок) — перебор падает до ~40 попыток в сутки (≈ 1,5 % за семестр); по желанию — 8-значные коды (нужно выдать новые).

### 2. Нельзя заменить один утёкший код, не меняя остальные — серьёзность: важно
- Бриф (риски): «Личный код может утечь — меняется … за минуту, остальные коды не затрагиваются».
- Получилось: есть только `createActivistCodes` — выдаёт новые коды всем сразу.
- Предлагаемое исправление: меню в таблице «Расписание 322 → Новый код для…» (выбор имени, код показывается только вам), остальные коды не меняются.

### 3. Открытая страница группы может показывать правку через 6 минут — серьёзность: важно (признак готовности)
- Шаги: страница группы открыта; активист сохраняет правку.
- Ожидалось: не позже 5 минут.
- Получилось: страница обновляет данные раз в 5 минут, у сервера кэш 60 с → до 6 минут (при возвращении на вкладку — сразу).
- Исправление: обновлять раз в 4 минуты.

### 4. 320 px: названия предметов рвутся посреди слова — серьёзность: мелочь
- «Муниципал|ьное право», «Гражданск|ий процесс» на экране группы при ширине 320 (бриф требует от 360 — там нормально).
- Исправление: переносы по слогам (`hyphens: auto`) вместо разрыва в любом месте.

### 5. 320 px: имя активиста в шапке редактора сжимается до одной буквы — серьёзность: мелочь
- Исправление: перенести имя на свою строку на узких экранах.

### 6. Что попадёт в открытый репозиторий — серьёзность: решить при выпуске
- Бесплатный GitHub Pages работает только из открытого репозитория. В нём сейчас: имена активистов (`ACTIVISTS` в коде сервера), история ДЗ и ссылок 14.09–31.10 (`site/data/demo-entries.json`), прототип с данными из переписки. Кроме того, ответ сервера (его видит любой со ссылкой) содержит, кто последним правил пару.
- Решение — на этапе выпуска: вынести имена в свойства скрипта, демо-данные заменить обезличенными или убрать из публикации.
