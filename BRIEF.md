# Бриф: Расписание группы 322

## Задача
Активисты каждую неделю вручную перепечатывают и оформляют расписание с аудиториями и ДЗ в Telegram, а одногруппники ищут нужный день в длинной ленте. Нужен сайт, где расписание строится из официального шаблона само, активисты за несколько минут дописывают ДЗ и изменения, а группа сразу видит «сегодня» и «завтра».

## Пользователи
- **Одногруппники (вся группа 322)** — открывают с телефона перед парами или вечером накануне: где пара, что готовить, что изменилось.
- **Активисты (2 человека)** — на выходных перед неделей заполняют ДЗ и изменения; в течение недели вносят срочные замены. Чаще с телефона. Главные пользователи по удобству — подробно в `ACTIVIST_UX.md`.
- **Владелец (Еремей)** — один раз настраивает, раздаёт коды, правит шаблон раз в семестр.

## Главный сценарий
1. Активист открывает «Для активистов» (код запомнен на телефоне) — сразу видна следующая неделя, собранная по шаблону (верхняя/нижняя).
2. Нажимает на семинар → «Вставить ссылку» или «Как в прошлый раз» → закрывает. Сохраняется само.
3. При замене или переносе — две-три кнопки в карточке пары, с выбором «только в этот день / с этого дня и дальше».
4. Копирует текст для Telegram по дням и публикует, как привык.
5. Одногруппник открывает сайт → сразу видит пары на сегодня (вечером — на завтра) с ДЗ и пометками об изменениях.

## Первая версия — обязательно
1. **Просмотр для группы:** «Сегодня», «Завтра», «Неделя» — время, номер пары, аудитория, предмет, тип, ДЗ, ссылки, пометки; перенесённые и отменённые пары видны с объяснением; свежие изменения помечены; вкладка «ДЗ» — что готовить на ближайшие дни.
2. **Автосборка недели:** два шаблона (верхняя/нижняя) от опорной недели 14.09.2026 = верхняя; постоянные изменения «с даты»; постоянные пометки шаблона («Сменка», «отмечает сама»); номера пар считаются сами.
3. **Редактор недели для активиста:** мастер «Заполнить» по семинарам по очереди, отметка «ДЗ нет»; ДЗ (подпись с частыми фразами, ссылки вставкой из буфера с проверкой темы, «Как в прошлый раз»), пометка дня, замена аудитории/времени/преподавателя (только в этот день или с этого дня), отмена пары, перенос на другую дату, дополнительная пара.
4. **Надёжное сохранение:** личные коды активистов, автосохранение, работа без сети с отправкой позже, защита от одновременной правки, журнал изменений и «Отменить».
5. **Тексты для Telegram:** неделя целиком, по дням, сообщение об изменении — в нынешнем оформлении.

## Ограничения
- Бесплатно, без своего сервера: сайт — статический, данные — Google Таблица, запись — Google Apps Script.
- Русский язык; время — московское (Санкт-Петербург).
- Телефон в первую очередь: ширина от 360 px, кнопки ≥ 44 px, работа одной рукой; без сети показывается последняя загруженная неделя.
- Семестр: с 14.09.2026 по 31.12.2026 (конец — рабочее значение, уточнится).

## Признаки готовности
**Сборка и просмотр**
- [ ] Для каждой недели с 14.09 по 31.10.2026 собранное расписание совпадает с сообщениями активистов по предметам, времени и аудиториям (с учётом задокументированных изменений: ГПП по вторникам → 219; муниципальное во вторник нижней → 211; физкультура).
- [ ] При открытии сайта без нажатий показан текущий день; после 18:30 — следующий учебный.
- [ ] Изменения последних 48 часов помечены на сайте для группы.
- [ ] Экран 360 px — без горизонтальной прокрутки; без интернета открывается последняя загруженная неделя.

**Удобство активиста** (замер секундомером с телефона)
- [ ] Неделя как 26.10–31.10 заполняется не дольше 5 минут.
- [ ] ДЗ «подпись + 1 ссылка» — не больше 4 нажатий после открытия недели; «Как в прошлый раз» — 2 нажатия.
- [ ] Разовая замена аудитории — не дольше 15 секунд; перенос пары — не дольше 1 минуты.
- [ ] Замена «с этого дня и дальше» меняет все следующие недели этой половины и не меняет прошлые.
- [ ] Перенос: в исходный день пара зачёркнута с «перенесена на <дата>, <время>, ауд. <…>»; в новый день — по времени с «перенос с <дата>» и тем же ДЗ; номера пересчитаны; «Отменить перенос» возвращает оба дня.
- [ ] Ссылка из темы другой дисциплины вызывает предупреждение, но сохранить её можно.

**Надёжность**
- [ ] Неверный код — отказ, таблица не меняется; после 10 неверных попыток — пауза 10 минут.
- [ ] Правка без сети не теряется и попадает в таблицу после появления сети, без дублей.
- [ ] Две одновременные правки одной пары не затирают друг друга молча.
- [ ] Каждое изменение есть в журнале (кто, когда, было, стало); «Отменить» в течение 10 секунд возвращает прежнее.
- [ ] После сохранения изменение видно на сайте у другого человека не позже чем через 5 минут.

**Telegram**
- [ ] Текст недели 26.10–31.10 по содержанию совпадает с сообщениями 43–48; копирование одного дня — 1 нажатие; для переноса есть короткий текст об изменении.

## Риски и допущения
- Решение пользователя: просмотр — всем, у кого есть ссылка; редактирование — по личным кодам активистов.
- [допущение] Шаблоны: официальное расписание V семестра 2026–2027 с поправками (ГПП-семинары во вторник — 219; муниципальное, вторник нижней — 211; физкультура: спортзал — верх, спорткомплекс им. Алексеева — низ).
- [допущение] Названия предметов — сокращения, как у активистов (ГПП, УПП, ГП, УП, ТП, ОСД, МП).
- Персональные данные: в ДЗ встречаются имена одногруппников. Открытый сайт = публикация (Федеральный закон от 27.07.2006 № 152-ФЗ «О персональных данных»). Меры: без фамилий в ДЗ, noindex, ссылка только внутри группы. Риск снижается, но не исчезает.
- Объём первой версии вырос (редактор с помощниками, работа без сети, журнал) — сборка займёт больше вечеров; порядок шагов в плане позволяет показать активистам рабочий редактор раньше, чем всё готово.
- Сервисы Google сейчас доступны в РФ, но гарантии нет; данные выгружаются из таблицы.
- Главный нетехнический риск — активисты не перейдут. Прототип редактора показываем им до полной сборки.
- Личный код может утечь — меняется в настройках скрипта за минуту, остальные коды не затрагиваются.

# Версия 0.2 (ред. 1, 01.11.2026)

## Задача
После выпуска 0.1 три вещи всё ещё требуют таблицы или ручной работы: новый семестр и любые изменения шаблона делаются только в Google Таблице; старые сообщения активистов нельзя перенести на сайт иначе как вручную; открытые данные сайта показывают всем, кто из активистов правил пару.

## Главный сценарий
1. Перед новым семестром активист открывает «Шаблон и семестр», задаёт даты семестра и опорную неделю, берёт текущий шаблон за основу и правит пары (день, верх/низ, время, предмет, тип, аудитория, преподаватель, пометка) — изменения действуют с выбранной даты, прошлые недели не меняются.
2. Видит предпросмотр ближайшей недели по новому шаблону и предупреждения (пары накладываются, пустой предмет) → «Сохранить».
3. Активист вставляет в редактор сообщение (или несколько сообщений) из Telegram в привычном формате → сайт показывает, что и к каким парам запишет (подписи, ссылки, пометки дня), предупреждает о расхождениях с расписанием → «Записать».
4. Одногруппники и любой со ссылкой не видят, кто из активистов что правил; журнал в таблице по-прежнему хранит имена.

## Версия 0.2 — обязательно
1. **Шаблон и семестр через сайт** (доступно всем активистам по их кодам): даты семестра, опорная неделя и половина; добавить / изменить / удалить пару шаблона и предмет (название, сокращение, цвет); каждое изменение шаблона действует **с выбранной даты** — недели до неё остаются как были (вместе с ДЗ, заменами и переносами).
2. **Импорт из Telegram:** вставка одного или нескольких сообщений в формате активистов → разбор по дням и парам → предпросмотр → запись ДЗ, ссылок и пометок дня. Аудитории и время из сообщения не меняют расписание — при расхождении только предупреждение.
3. **Имена скрыты:** в открытых данных сайта, на страницах группы и в редакторе нет имён активистов (в конфликте — «другой активист»); имена остаются только в листах таблицы (журнал, «кто»).

## Признаки готовности 0.2
**Шаблон и семестр**
- [ ] Изменение пары шаблона «с 09.02.2027» меняет недели с 09.02.2027 и не меняет ни одну неделю 14.09–31.10.2026 (сверка 42 дней из переписки проходит без изменений).
- [ ] Новый семестр (даты, опорная неделя, новый шаблон на основе старого) настраивается с телефона не дольше 15 минут (замер вместе с владельцем).
- [ ] Перед сохранением шаблона показан предпросмотр ближайшей недели по нему; накладывающиеся пары и пустые обязательные поля — предупреждение/ошибка у поля.
- [ ] Удаление пары шаблона не ломает прошлые недели: записи (ДЗ, замены, переносы) на старые даты продолжают показываться.
- [ ] Каждое изменение шаблона и настроек есть в журнале; «Отменить» в течение 10 секунд возвращает прежнее.

**Импорт из Telegram**
- [ ] Вставка сообщений 43–48 (неделя 26–31.10) даёт те же ДЗ, ссылки и пометки, что в истории проекта (`site/data/demo-entries.json`) для этой недели.
- [ ] Предпросмотр показывает каждую запись до сохранения; строки, которые не удалось отнести к паре, перечислены, а не потеряны.
- [ ] Уже вписанное другое ДЗ не затирается молча: для каждой такой пары — выбор «оставить / заменить / объединить».
- [ ] Расхождение аудитории или времени с расписанием даёт предупреждение и не меняет расписание.
- [ ] Импорт недели (6 сообщений одной вставкой) — не больше 3 нажатий после вставки.

**Имена**
- [ ] Ответ сервера для сайта (чтение данных) не содержит имён активистов — проверка тестом и живым запросом.
- [ ] В редакторе и диалоге конфликта имена не показываются («другой активист»); в листах таблицы «кто» и журнал по-прежнему заполняются.

## Риски и допущения 0.2
- Шаблон правят все активисты (решение владельца): ошибка в шаблоне ломает расписание на месяцы вперёд. Меры: изменения только «с даты», предпросмотр, «Отменить», журнал, восстановление прошлой версии шаблона.
- [допущение] Сообщения для импорта — в формате переписки (день капсом, дата ДД.ММ.ГГГГ, время с надстрочными цифрами, номера-«клавиши» с U+FE0F и без, «пара/аудитория - предмет»); опечатки и разные пробелы допускаются.
- [допущение] Импорт пишет только в даты, на которые на сайте есть пары; дни вне расписания — в список «не удалось отнести».
- Скрытие имён в редакторе — активисты не видят, кто из коллег правил пару; при конфликте они узнают об этом только как «другой активист».
